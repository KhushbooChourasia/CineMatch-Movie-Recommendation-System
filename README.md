# CineMatch - Movie Recommendation System

CineMatch is a movie recommendation web application
built using Python, Pandas, Scikit-learn, and Streamlit.

## Features
- Content-based movie recommendations using TF-IDF
  and cosine similarity.
- Item-based collaborative filtering using movie ratings.
- Movie ratings and rating counts.
- Interactive Streamlit interface.
- Download recommendations as a CSV file.

## Dataset
MovieLens Small Dataset from GroupLens Research:
https://grouplens.org/datasets/movielens/

## Technologies
- Python
- Pandas and NumPy
- Scikit-learn
- TF-IDF
- Cosine Similarity
- Streamlit

## Run Locally
Install the required libraries:

pip install -r requirements.txt

Run the application:

streamlit run app.py
